# 典藏版外观校准 · G1

日期 2026-10-27。单位 10 mm / 场景单位；+Z 屏幕、−Z 背面。官方包络 164.5 × 78.7 × 8.15 mm 不含相机突出量的机械定义未另获测绘确认。模型中框以此控制，不能把镜头凸起一起压到 8.15 mm。

## 归一化方法

以官方标注后视图 body bounds (128,127)–(537,984) 为基准，像素宽 409，中心 (332.5,555.5)。u=(x−332.5)/409；v=(555.5−y)/409；照片投影毫米=78.7(u,v)。后视图 u 与场景 X 方向相反。完整 16 点及像素在 [calibration.json](calibration.json)，由 `python scripts/calibrate-reference.py` 重算。
